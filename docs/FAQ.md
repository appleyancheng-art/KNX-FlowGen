# 常见问题

**KNX FlowGen 能替代 ETS6 吗？**  
不能。它用于组地址规划、整理、转换与交付；ETS 的设备编程、参数配置和总线下载仍需在 ETS 完成。

**能直接导入完整 .knxproj 吗？**  
当前流程导入 ETS6 导出的组地址 XML，不是完整 ETS 工程文件。

**精装房现场记录有什么用？**  
把现场手动抓取的组地址填入标准 Excel 模板，导入后保留原始地址与 DPT，二次编辑并转为 XML、网关模板或交付资料。

**需要联网吗？**  
本地规划和编辑使用打包资源；激活及受保护导出依赖现有在线授权检查。

**下载免费是否表示软件免费或开源？**  
不是。下载安装包与购买软件授权是两件事；以购买页面和软件授权提示为准。

**安装失败提示文件无法写入？**  
先保存项目并退出正在运行的 KNX FlowGen，再重试覆盖安装。不要忽略写入失败。

**网关适配文件可以不检查直接导入吗？**  
请先核对地址、DPT、方向、目标参数和房间映射，少量验证后再批量导入。详见适配补充说明。
